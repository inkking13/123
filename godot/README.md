# Raid Commander

Гильдейская рейд-игра на Godot 4.5: найм и драфт отряда, лагерь, снаряжение,
профессии, контракты, подземелья и пошаговый бой на 3D-поле в духе Wartales.

## Как устроено

- `app.tscn` + `scripts/app.gd` — оболочка: фон, переходы между экранами,
  кнопка «назад».
- `scripts/core/` — вся логика игры без интерфейса:
  `db.gd` (данные из `data/*.json`), `game.gd` (состояние гильдии, сохранение
  в `user://save.json`, навигация), `battle.gd` (бой), `events.gd`, `checks.gd`.
- `scripts/screens/` — экраны, `scripts/ui/` — общий набор элементов
  (пергамент, чернила, сургуч; шрифты Alegreya, иконки Phosphor из `data/icons.json`).
- `scripts/screens/combat.gd` — интерфейс боя в духе Wartales: сверху
  противник, его здоровье и шкала очерёдности (лица со здоровьем), справа
  сверху цели; снизу карточка героя, чей ход, панель навыков (квадраты с
  номерами клавиш и подсказками) и темп боя.
- Классы в духе World of Warcraft (`data/specs.json`, `spellbook.json`,
  `talentTrees.json`): у каждого из 8 классов три специализации, и от неё
  зависит роль; свой ресурс (ярость, мана, энергия, концентрация, сила рун);
  книга заклинаний по уровню и специализации; три классические ветки
  талантов — очко за уровень, ранги, ряды открываются на 0/5/10/15/20 очках
  в ветке, в конце ветки — новое заклинание. Экран `screens/talents.gd`.
- Открытая карта в духе Wartales (`scripts/core/world.gd`, `world_view.gd`,
  `screens/world.gd`, `screens/town.gd`): по 3D-региону на каждую землю,
  отряд идёт к точке касания. На карте подземелья земли, город (рынок,
  таверна, контракты, провизия, ночлег), сундуки, места сбора, дороги в
  соседние земли и бродячие банды — днём и ночью (ночью они зорче и бьют
  сильнее). Путь тратит часы, часы — пайки и силы; привал в любом месте.
- `scripts/battle_view.gd` — 3D-поле боя: арена, клетки, камера (поворот
  пальцем, масштаб щипком), касания по врагам и клеткам.
- `scripts/unit.gd` — боец: тело со скелетом, доспехи комплекта (садятся на
  тот же скелет по именам костей), оружие в руках, анимации.
- Рендерер Mobile (Vulkan) с откатом на OpenGL; в браузере — Compatibility.

## Телефон и компьютер

Раскладка выбирается по форме окна (`App.wide`):

- **высокое окно** (телефон) — колонка экранов и нижняя панель вкладок;
- **широкое окно** (компьютер, браузер) — вкладки в полосе слева, списки в две
  колонки, лагерь в две колонки, в бою панели по углам и поле на весь экран.
  Помогают `UI.cards()` (список карточек), `UI.split()` (две колонки),
  `make_page(..., wide_w)` и `span_column()`.

Окно можно тянуть — раскладка перестраивается на лету. На компьютере
кнопки подсвечиваются под мышью, у списков есть полоса прокрутки, а в
настройках — масштаб интерфейса.

Клавиши: Esc — назад, Enter — главная кнопка экрана, F11 или Alt+Enter —
полный экран. В бою: 1–9 — действия (или кого лечить), Пробел — пропустить
перемещение, A — автобой, X — скорость.

Камера боя: перетаскивание (на компьютере — и правой кнопкой) поворачивает
и наклоняет, щипок или колесо — масштаб; кнопки слева/справа и клавиши
Q/E — поворот на 45°, +/− — масштаб, PgUp/PgDn — наклон, R — вернуть.
Стоящие бойцы разворачиваются к ближайшему противнику.

## Данные и ресурсы

- `data/*.json` — герои, предметы, подземелья, задания и прочее. Это исходник:
  правьте прямо здесь.
- `assets/` — модели (`.glb`) и картинки. Текстуры, которые импорт достаёт из
  моделей, не хранятся в git — Godot создаёт их сам.

## Проверки

```
godot --headless --path . -s res://tests/loadall.gd   # компилирует все скрипты
godot --headless --path . -s res://tests/smoke.gd     # драфт и два подземелья на автобое
godot --headless --path . -s res://tests/spells.gd    # каждое заклинание каждой специализации
godot --headless --path . -s res://tests/world.gd     # карта: сундук, привал, банда, подземелье, переход
```

Скриншот без телефона:
`godot --path . -- --shot=out.png [--demo] [--go=экран] [--wait=секунды] [--auto]`.

## Сборка

GitHub Actions при каждом изменении в `godot/`:

- `build-apk.yml` — APK и архив для Windows, выкладываются релизом `game-N`
  (подписан ключом `android/proto.keystore`, пароль `raidproto`, — только для
  установки на свой телефон);
- `deploy-web.yml` — версия для браузера на GitHub Pages (из `main`).
