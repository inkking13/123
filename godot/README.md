# Raid Commander

Гильдейская рейд-игра на Godot 4.5: найм и драфт отряда, лагерь, снаряжение,
профессии, контракты, подземелья и пошаговый бой на 3D-поле в духе Wartales.

## Как устроено

- `app.tscn` + `scripts/app.gd` — оболочка: фон, переходы между экранами,
  кнопка «назад».
- `scripts/core/` — вся логика игры без интерфейса:
  `db.gd` (данные из `data/*.json`), `game.gd` (состояние гильдии, сохранение
  в `user://save.json`, навигация), `battle.gd` (бой), `events.gd`, `checks.gd`.
- `scripts/screens/` — экраны, `scripts/ui/` — общий набор элементов
  (пергамент, чернила, сургуч; шрифты Alegreya, иконки Phosphor из `data/icons.json`).
- `scripts/battle_view.gd` — 3D-поле боя: арена, клетки, камера (поворот
  пальцем, масштаб щипком), касания по врагам и клеткам.
- `scripts/unit.gd` — боец: тело со скелетом, доспехи комплекта (садятся на
  тот же скелет по именам костей), оружие в руках, анимации.
- Рендерер Mobile (Vulkan) с откатом на OpenGL; в браузере — Compatibility.

## Данные и ресурсы

- `data/*.json` — герои, предметы, подземелья, задания и прочее. Это исходник:
  правьте прямо здесь.
- `assets/` — модели (`.glb`) и картинки. Текстуры, которые импорт достаёт из
  моделей, не хранятся в git — Godot создаёт их сам.

## Проверки

```
godot --headless --path . -s res://tests/loadall.gd   # компилирует все скрипты
godot --headless --path . -s res://tests/smoke.gd     # драфт и два подземелья на автобое
```

Скриншот без телефона:
`godot --path . -- --shot=out.png [--demo] [--go=экран] [--wait=секунды] [--auto]`.

## Сборка

GitHub Actions при каждом изменении в `godot/`:

- `build-apk.yml` — APK, выкладывается релизом `game-N`
  (подписан ключом `android/proto.keystore`, пароль `raidproto`, — только для
  установки на свой телефон);
- `deploy-web.yml` — версия для браузера на GitHub Pages (из `main`).
