# Raid Commander — прототип на Godot 4

Один бой из игры, пересобранный на Godot 4.5, чтобы сравнить картинку и скорость
с основной версией (`../app`, Expo + three.js) на одном и том же телефоне.

- Арена — «Проклятое поле боя» из игры (те же модели, жаровни и декор).
- Пять героев (Каелен, Борин, Родерик, Сильвана, Тэдиус) в своих стартовых
  доспехах и с оружием из игры против двух скелетов-мечников, лучника и мага.
- Пошаговый бой: в свой ход нажми на врага, чтобы ударить; Тэдиус лечит союзника
  или бросает колбу во врага. Свайп по экрану поворачивает камеру.
- Кнопка «Графика»: высокая (тени, свечение, сглаживание, мусор на земле)
  или низкая (для слабого телефона). Счётчик FPS — внизу слева.

## Как устроено

- `scripts/main.gd` — мир (свет, небо, туман, цветокоррекция), арена, камера,
  интерфейс и ходы боя. Всё собирается в коде, сцена `main.tscn` пустая.
- `scripts/unit.gd` — боец: тело Meshy со скелетом, доспехи комплекта
  (садятся на тот же скелет по именам костей, тело под ними вырезается),
  оружие в руках (перенос `gripIn` из `app/src/battle3d/MeshyModel.tsx`), клипы.
- `shaders/post.gdshader` — один проход поверх кадра: палитра, тёплые тени,
  виньетка, зерно.
- Рендерер Mobile (Vulkan); если телефон его не тянет, Godot сам
  переключается на OpenGL (Compatibility).

## Модели

Модели не лежат в этой папке, их копирует из `../app/assets/models`
скрипт `tools/sync_assets.sh` — запусти его перед открытием проекта в редакторе.

## Сборка

APK собирает GitHub Actions (`.github/workflows/build-godot-proto.yml`) при
каждом изменении в `godot/` и выкладывает его пре-релизом `godot-proto-N`.
Подписан одноразовым ключом `android/proto.keystore` (пароль `raidproto`) —
только для установки на свой телефон.

Скриншот без телефона: `godot --path . -- --shot=out.png [--low] [--fight]`.
